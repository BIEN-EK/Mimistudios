# MIMI STUDIOS website

Static GitHub Pages-ready site. No build step is required.

## Publish
1. Create a GitHub repository, e.g. `mimi-studios`.
2. Upload `index.html`, `styles.css`, `script.js` to the repository root.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.

## Replace before launch
- Placeholder location
- Instagram/TikTok links (`href="#"`)
- `hello@example.com`
- Opening information
- Eventually replace the abstract hero graphic with real MIMI photography.

Google Fonts are loaded remotely; the rest of the site is self-contained.
